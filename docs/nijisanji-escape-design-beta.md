# にじさんじ脱出ゲーム設計書（難易度1）ベータ版

> **ネタバレ注意**：この設計書には謎の答えとヒントがすべて載っています。遊ぶ予定の人は読まないでください。
>
> 非公式の二次創作です。ANYCOLOR株式会社およびにじさんじ公式とは関係ありません。

最終更新：2026-10-26（ベータ版）

## 概要

「深夜のにじさんじ配信スタジオに閉じ込められた新人スタッフが、0時の記念配信が始まる前に脱出する」という設定で、5部屋・5つの謎を約90分で解きます。謎の答えはすべてワールド内の情報だけで出せるようにし、ライバーの知識がなくても詰まらない作りにします。

| 項目 | 内容 |
| --- | --- |
| 対応 | Java版（推奨は1.21系。仕掛けの段階で確定） |
| 人数 | 2人以上を想定、ソロでもクリア可能 |
| 難易度 | 3段階のうち最も易しい1作目 |
| モード | アドベンチャーモード（ブロックは壊せない） |

| 部屋 | 謎 | 目安時間 |
| --- | --- | --- |
| 0. ロビー | ルール説明（謎なし） | 5分 |
| 1. エントランス | 入館コード（数え謎） | 10分 |
| 2. 楽屋 | 差し入れの論理パズル | 15分 |
| 3. 配信ブース | コメント欄と配信チェックリスト | 15分 |
| 4. 編集室 | 虹色の暗号 | 20分 |
| 5. メインスタジオ | 4つのかけらで最終謎 | 15分 |
| 予備 | 迷った時間・ヒント | 10分 |

## ストーリー

**導入（ロビーの看板・タイトル表示）**

今日はあなたたち新人スタッフの初出勤日。深夜0時からは大事な記念配信が予定されています。ところが準備中に停電が起き、セキュリティが誤作動してスタジオの扉が全部ロックされてしまいました。ライバーさんたちが残したメモを頼りに、各部屋のロックを解除して「記念配信データ」のかけら4つを集め、メインスタジオで配信を始めましょう。

**エンディング**

正しいボタンを押すとスタジオの照明が戻り、「配信開始！」のタイトルと花火。屋上に移動してライバーからのお礼の手紙とクレジット、クリアタイムを表示します。間違ったボタンは「配信事故」の小ネタを出してやり直しにします（バッドエンドで終わらせない）。

登場するライバーは楽屋の4人だけで、友人たちの推しに合わせて入れ替えられる「枠」にしています。台詞は本人の口調を真似る程度に留め、実在の発言や設定を断定しないようにします。

## 部屋の構成

部屋は一本道でつながり、謎を解くと次の扉が開きます。各部屋の出口の廊下に「記念配信データのかけら」を入れたチェストを置きます。

1. **ロビー**（10×10程度）：ルール看板、ヒントの使い方、スタートボタン。扉の開け方の練習を兼ねる。
2. **エントランス**（12×12）：受付カウンター、観葉植物、絵画、待合の椅子。「かけら①」。
3. **楽屋**（12×8）：ライバー4人分のドレッサーと納品箱、隣に小さな給湯室。「かけら②」。
4. **配信ブース**（10×10）：壁一面の「コメント欄」看板、配信卓、レバー4本の配信設定パネル。「かけら③」。
5. **編集室**（12×10）：天井に羊毛の虹、ガラス越しに見える小部屋。「かけら④」。
6. **メインスタジオ**（14×14）：ステージと文字ボタン8つ。正解で屋上（エンディング）へ。

## 謎の一覧と答え

数字の答えはチャットで `/trigger code set 3142` のように入力します（ロビーで練習させる）。どの謎も答えは部屋の中にある情報だけで出ます。

| # | 部屋 | 謎 | 答え | 入力方法 | もらえるかけら |
| --- | --- | --- | --- | --- | --- |
| 1 | エントランス | 条件付きの数え謎 | 3142 | /trigger | 青い羊毛「し」 |
| 2 | 楽屋 | 差し入れの論理パズル | A金のニンジン・Bりんご・Cケーキ・Dクッキー | 納品箱に入れる | 紫の羊毛「ん」 |
| 3 | 配信ブース | コメント欄を時刻順に→伝言でレバー4本 | 4721 → マイクON・カメラOFF・BGM OFF・照明ON | /trigger＋レバー4本 | 赤い羊毛「は」 |
| 4 | 編集室 | 鏡うつしの虹色暗号 | 4173 | /trigger | 黄色の羊毛「い」 |
| 5 | メインスタジオ | かけらを虹の順に→文字ボタンを順番に押す | は→い→し→ん | 8個の文字ボタン | ― |

### 謎1 入館コード（エントランス）

受付の看板は「入館コード＝咲いた花／空っぽの額縁／消えた灯り／白紙の名札」。ただ数えるだけでなく、条件に合うものだけを数えます。

- 植木鉢6個のうち、花が植わっているのは3個（残りはサボテン・苗木・枯れ木）→ 3
- 額縁6個のうち、空のもの1個 → 1
- レッドストーンランプ6個のうち、消えているもの4個（1個はカウンターの裏）→ 4
- 名札の看板5枚のうち、何も書いていないもの2枚（1枚は受付の内側）→ 2

答えは **3142** です。

### 謎2 差し入れの論理パズル（楽屋）

楽屋には左からA・B・C・Dの順でドレッサーが並びます。給湯室の発注メモに「今日の差し入れはクッキー・りんご・ケーキ・金のニンジンの4つ。一人1つずつ」と書き、チェストにはその4つとダミー（パン、スイカ、パンプキンパイ、金のりんご）を入れます。各ドレッサーの書き置きメモは次のとおりです。

- A「甘いお菓子は今日はいらない。果物も気分じゃないな」
- B「オーブンで焼いたものはちょっと…」
- C「りんごを頂いた人の楽屋は、わたしのすぐ左だよ」
- D「ろうそくは立てなくていいよ」

解き方：Aはどちらも当てはまらない金のニンジン。Bは焼き菓子以外で、金のニンジンはAなのでりんご。Cのすぐ左がBなので、Cのメモと矛盾しない。Dはケーキ以外でクッキー、残るケーキがCです。答えは **A金のニンジン・Bりんご・Cケーキ・Dクッキー**。メモの口調は友人の推しに合わせて書き換えられます。

### 謎3 コメント欄と配信者の伝言（配信ブース）

壁の「配信ルール」の貼り紙に「モデレーターの名前は青い。大事なことは古い順に頭文字だけ」。コメント欄の看板14枚には時刻が付いていて、青い名前のモデレーター7人と、灰色の名前の視聴者7人のコメントがバラバラに並んでいます。

| 時刻 | モデレーターのコメント |
| --- | --- |
| 20:41 | よし、みんな集まってきたね |
| 20:43 | ん？音量小さくない？ |
| 20:45 | なつかしいBGMだ |
| 20:47 | ながら見の人もゆっくりしてね |
| 20:49 | にぎやかになってきた |
| 20:52 | いよいよだね |
| 20:55 | ちゃんと水分とってね |

古い順に頭文字を読むと「よんななにいち」で、**4721** が「配信者ロッカー」の暗証番号です（`/trigger code set 4721`）。コメント欄を読まないと番号が分からないので、総当たりでは開けられません。ロッカーが開くと伝言の本が出てきます。伝言はそのままの指示ではなく、繋ぎ合わせて読む形です。

- 「今日は声だけの配信。顔は映さないよ」→ カメラOFF
- 「声が届かなかったら意味ないよね」→ マイクON
- 「BGMはマイクと反対にしておいて」→ BGM OFF
- 「照明はカメラと逆で」→ 照明ON

配信卓のレバー4本（ONにすると台が光る）をその通りにすると扉が開きます。レバーはロッカーを開けた後でないと反応しません。

### 謎4 鏡うつしの虹色暗号（編集室）

天井に羊毛で虹を作ります（赤・橙・黄・黄緑・水色・青・紫）。入口には「にじは7色。はじまりは1」だけを書き、編集長のメモに「パスワードは窓の向こうの4色。ただし向こうは鏡の国。見たまま読んではいけない」。奥の窓からは左から黄・紫・赤・黄緑が見えるので、反対から読んで黄緑(4)・赤(1)・紫(7)・黄(3)。答えは **4173** です。天井と小部屋は同じブロックを使い、黄緑と緑で迷わないようにします。

### 謎5 配信開始（メインスタジオ・最終）

集めた4つのかけらは色付きの羊毛で、金床でひらがな1文字の名前が付いています（青「し」、紫「ん」、赤「は」、黄「い」）。ステージの看板は「かけらをにじの順に。それが今夜の合言葉」。ステージには「は・い・し・ん・さ・て・ろ・く」の文字ボタン8個があり、虹の順（赤→黄→青→紫）に **は→い→し→ん** と押すと配信が始まります。順番を間違えると「配信事故」の小ネタが出て最初からやり直しです。

## ヒント

各部屋に「ヒントボタン」を3つ並べ、押すとチャットにヒントが出ます。弱い順に①方向性、②ほぼ答え、③答えです。

| 謎 | ① 方向性 | ② ほぼ答え | ③ 答え |
| --- | --- | --- | --- |
| 1 | 条件に合うものだけ数えよう | カウンターの裏と受付の内側も見た？ | 3142 |
| 2 | 発注メモの4つから、決めやすい人から埋めよう | Aは金のニンジン、Bはりんご | A金のニンジン・Bりんご・Cケーキ・Dクッキー |
| 3 | 青い名前のコメントを時刻順に | 「よんななにいち」。伝言はカメラから決める | 4721、マイクON・カメラOFF・BGM OFF・照明ON |
| 4 | 天井の虹は数字の表 | 鏡なので右から読む | 4173 |
| 5 | かけらの色に注目 | 赤→黄→青→紫の順に並べよう | は→い→し→ん |

ヒントを押した回数を記録して、エンディングでクリアタイムと一緒に表示すると、難易度2・3への挑戦意欲にもつながります。

## 仕掛けの作り方

謎の内容が固まってから作ります。予定しているのは、数字入力の /trigger、納品箱の中身を判定するコマンドブロック、レバー4本の組み合わせ錠（レッドストーン）、ヒントボタンの tellraw、文字ボタンの順番判定、エンディングの title と花火です。

## ソロと複数人の両対応

- 「2人同時に押す」仕掛けは使わず、複数入力はボタンではなくレバーにする（一人で順番に切り替えられる）。
- 情報と入力の場所を離して「読み上げ役と入力役」に分かれるようにしつつ、一人でも歩けば届く距離にする（謎3・謎4）。
- 謎2は4カ所を手分けでき、謎1は4種類を分担して数えられる。
- かけらはチェストから取る形にし、誰が持っていても進めるようにする（最終謎は全員が見れば解ける）。
- 一人だと時間が伸びるので、ソロの目安は90分、複数人は60〜75分を想定。

## 二次創作ガイドラインへの配慮

友人内での個人・非営利の遊びとして作る前提です。公式ロゴや立ち絵の画像はそのまま使わず、色や言葉のモチーフと自作ドット絵で表現します。ロビーに「非公式の二次創作です」と明記し、ライバーを貶める台詞や設定は入れません。ワールド配布や配信をする場合は、ANYCOLORの公式ガイドラインの最新版を確認してからにします。
